- Responsive design

### 3. Local Storage Task Manager

A responsive task management application that allows users to create, manage, search, filter, complete, and delete tasks.

*Technologies Used*
- HTML
- React
- JavaScript
- Tailwind CSS
- LocalStorage

*Features*
- Add new tasks
- Set task priority
- Mark tasks as completed
- Delete tasks
- Search tasks
- Filter by All, Active, and Completed
- Clear completed tasks
- Task statistics
- Persistent data using browser LocalStorage
- Responsive interface

Folder: Task-Manager/
